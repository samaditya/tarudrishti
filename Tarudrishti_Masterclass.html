The Foundation: pgvector & Semantic Caching

Before we build the AI's "Brain," we need to build its "Memory." LLMs are expensive. If a user asks "How do I water my Snake Plant?" today, and asks the same question tomorrow, we shouldn't pay OpenAI twice.

What is an Embedding?

An embedding is a way to convert text into an array of floating-point numbers (a vector). In OpenAI's `text-embedding-3-small`, this array has 1536 numbers. Words with similar meanings end up as points close to each other in a 1536-dimensional space.

The Analogy: Think of embeddings as GPS coordinates. "Dog" is at [40.7, -74.0], "Puppy" is at [40.71, -74.01]. They are physically close. "Car" is in a completely different country.

Step 1: Setup the Database Model

We use PostgreSQL with the pgvector extension. This allows us to store these coordinates and calculate the distance between them using native SQL.

models.pyPython (SQLAlchemy)
from sqlalchemy import Column, Integer, String, DateTime
from sqlalchemy.sql import func
from database import Base
# IMPORTANT: Import Vector from pgvector
from pgvector.sqlalchemy import Vector

class SemanticCache(Base):
    __tablename__ = "semantic_cache"

    id = Column(Integer, primary_key=True)
    query_text = Column(String, nullable=False)
    response_text = Column(String, nullable=False)
    # We specify 1536 dimensions for OpenAI's embedding model
    embedding = Column(Vector(1536), nullable=False)
    created_at = Column(DateTime, default=func.now())

Step 2: The Caching Logic

When a user asks a question, we embed it, query the database for the closest vector using Cosine Distance, and if the distance is less than 0.15 (meaning 85% similarity), we return the cached answer.

Caching Logic SnippetPython
from openai import OpenAI
client = OpenAI()

# 1. Generate embedding for the new user query
response = client.embeddings.create(
    input="How often should I water my Pothos?",
    model="text-embedding-3-small"
)
query_embedding = response.data[0].embedding

# 2. Query the database using cosine_distance
# The < operator in SQL is translated by SQLAlchemy to utilize pgvector's index
cached_result = db.query(SemanticCache).filter(
    SemanticCache.embedding.cosine_distance(query_embedding) < 0.15
).first()

if cached_result:
    return cached_result.response_text # Zero LLM cost!
else:
    # ... call ChatOpenAI, get answer, and save it to SemanticCache
    pass

The Brain: LangGraph State Machine

Most basic AI apps pass a list of messages directly to an LLM. Tarudrishti uses LangGraph to create a multi-agent state machine. This allows the system to route tasks to specialized agents (nodes) rather than relying on one massive prompt.

graph LR Start((User Input)) --> Router{Router Node} Router -- intent: LOG_CARE --> Logger[Logger Agent] Router -- intent: DIAGNOSE --> Diag[Diagnostician Agent] Router -- intent: CHAT --> Botanist[Botanist Agent] Logger --> End((Output)) Diag --> End Botanist --> End

Step 1: Define the State

The "State" is a dictionary that is passed from node to node. Every node can read from it and return updates to it.

graph.pyPython (TypedDict)
from typing import TypedDict, Optional, List, Dict, Any
from langchain_core.messages import AnyMessage

class AgentState(TypedDict):
    messages: List[AnyMessage]     # Conversation history
    current_date: str              # Context for logging
    image_base64: Optional[str]    # Uploaded image
    intent: Optional[str]          # The router's decision
    final_response: Optional[Dict] # The final output to send to the user
    plants_context: List[Dict]     # Data injected from our database

Step 2: The Router Node (Using Structured Output)

The Router Node's only job is to decide what the user wants. We use OpenAI's Structured Output to force the LLM to return a strict Pydantic model. It cannot return conversational text; it MUST return JSON.

Router ImplementationPython
from pydantic import BaseModel
from langchain_openai import ChatOpenAI
from langchain_core.messages import SystemMessage

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)

# 1. Define the Schema
class IntentClassification(BaseModel):
    intent: str # Must be LOG_CARE, DIAGNOSE, or GENERAL_CHAT

def router_node(state: AgentState):
    # 2. Bind the schema to the LLM
    structured_llm = llm.with_structured_output(IntentClassification)
    
    sys_msg = SystemMessage(content=(
        "You are the central routing agent. Classify the user's input. "
        "If they talk about watering/fertilizing, return LOG_CARE. "
        "If they upload an image of a sick leaf, return DIAGNOSE."
    ))
    
    # 3. Invoke. The result is guaranteed to be an IntentClassification object.
    response = structured_llm.invoke([sys_msg] + state["messages"])
    
    # Return the update to the State
    return {"intent": response.intent}

Step 3: Compiling the Graph

Once you have defined your nodes (Router, Logger, Diagnostician), you tie them together with edges.

Compiling the State MachinePython
from langgraph.graph import StateGraph, END

# Initialize
builder = StateGraph(AgentState)

# Add Nodes
builder.add_node("router_node", router_node)
builder.add_node("logger_node", logger_node)
# ... add other nodes

builder.set_entry_point("router_node")

# Conditional Routing Function
def route_intent(state: AgentState):
    if state["intent"] == "LOG_CARE": return "logger"
    if state["intent"] == "DIAGNOSE": return "diagnostician"
    return "botanist"

# Add Conditional Edges from the Router
builder.add_conditional_edges(
    "router_node",
    route_intent,
    {
        "logger": "logger_node",
        "diagnostician": "diagnostician_node",
        "botanist": "botanist_node"
    }
)

# All worker nodes go to END
builder.add_edge("logger_node", END)

# Compile!
tarudrishti_app = builder.compile()

The API Gateway: FastAPI Integration

Now we expose the LangGraph application to the frontend using FastAPI. We also inject Database context here to enforce multi-tenancy (ensuring users only interact with their own plants).

Security Best Practice: Never let the LLM execute arbitrary SQL. The LLM extracts the intent and data. FastAPI executes the actual SQLAlchemy inserts using the authenticated `current_user.id`.
main.pyPython (FastAPI)
@app.post("/api/chat/orchestrator")
def orchestrate_chat(request: ChatRequest, db: Session = Depends(get_db), current_user = Depends(get_current_user)):
    
    # 1. Fetch user's plants from DB to give the LLM context
    user_plants = db.query(Plant).filter(Plant.user_id == current_user.id).all()
    plants_context = [{"id": p.id, "name": p.name} for p in user_plants]

    # 2. Setup the Initial State
    initial_state = {
        "messages": [HumanMessage(content=request.user_message)],
        "plants_context": plants_context,
        # ...
    }

    # 3. Invoke the Graph
    result_state = tarudrishti_app.invoke(initial_state)

    # 4. Handle DB Operations based on Intent
    if result_state["intent"] == "LOG_CARE":
        # Extract the structured data the Logger Agent generated
        actions = result_state["final_response"]["extraction"]["actions"]
        
        for action in actions:
            # Create a DB record manually in FastAPI
            db_log = CareLog(
                plant_id=find_plant_id(action["plant_name"]),
                action_type=action["action_type"]
            )
            db.add(db_log)
        db.commit()

    # 5. Return JSON to React
    return {"message": "Success", "data": result_state["final_response"]}

The Frontend: Vision & Compression

Sending 5MB raw images from an iPhone camera to a backend API will cause timeouts. Before we send data to FastAPI, we use the HTML5 Canvas API in React to compress the image client-side.

AIChatSheet.jsx - Compression UtilityJavaScript
async function compressAndEncodeImage(file) {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.onload = (e) => {
      const img = new Image();
      img.onload = () => {
        const MAX = 1024; // Maximum width or height
        let { width, height } = img;
        
        // Calculate new dimensions while maintaining aspect ratio
        if (width > MAX || height > MAX) {
          const ratio = Math.min(MAX / width, MAX / height);
          width = Math.round(width * ratio);
          height = Math.round(height * ratio);
        }
        
        // Draw to canvas
        const canvas = document.createElement('canvas');
        canvas.width = width;
        canvas.height = height;
        const ctx = canvas.getContext('2d');
        ctx.drawImage(img, 0, 0, width, height);
        
        // Export as 80% quality JPEG Base64
        const dataUrl = canvas.toDataURL('image/jpeg', 0.8);
        
        // Strip the HTML prefix to get raw base64 for OpenAI
        const base64 = dataUrl.replace(/^data:image\/jpeg;base64,/, '');
        resolve(base64);
      };
      img.src = e.target.result;
    };
    reader.readAsDataURL(file);
  });
}
