Under the Hood

The High-Level Analogy

Think of Tarudrishti not as a single chatbot, but as a high-tech garden management office.

The Garden Concierge

Imagine you walk into a prestigious botanical garden office. There isn't just one person there. Instead, there's a Receptionist (The Router) who listens to your request. Depending on what you say, they hand your file to a different specialist:

  • The Archivist (Logger) who records exactly when you watered the plants.
  • The Doctor (Diagnostician) who looks at a photo of a sick leaf through a microscope.
  • The Professor (Botanist) who answers general questions using a massive library of past research.

The Brain: LangGraph State Machine

How the AI decides what to do, loops back on mistakes, and maintains state.

What is a State Machine?

Traditional AI is like a straight line: Input → Prompt → Output. LangGraph turns it into a flowchart. The system maintains a "State" (a shared memory) and moves between "Nodes" (workers).

The Secret Sauce: Structured Output

The Router doesn't just "guess." We use Pydantic-validated Structured Output. The AI returns a JSON object with a specific schema, ensuring the code always knows which node to trigger.

graph.py - Router ImplementationPython
def router_node(state: AgentState):
    # This force-binds the LLM to return a valid IntentClassification object
    structured_llm = llm.with_structured_output(schemas.IntentClassification)
    
    sys_msg = SystemMessage(content=(
        "You are the central routing agent for Tarudrishti. "
        "Classify the user's input strictly into categories: LOG_CARE, DIAGNOSE, CHAT."
    ))
    
    response = structured_llm.invoke([sys_msg] + state["messages"])
    return {"intent": response.intent}

Semantic Caching: The Infinite Memory

How we save $ and cut latency by "remembering" similar questions.

The "Aura" Library

Standard caching is like looking for a book by its exact title. If you're off by one letter, you can't find it. Semantic Caching is like looking for a book by its "vibe."

When you ask "How do I water a Pothos?", we convert that sentence into a 1536-dimensional coordinate (a Vector). We then look in our database for any past questions that are geometrically close. If we find one that is 85% similar, we give you the stored answer instantly.

The pgvector implementation

We use the pgvector extension in PostgreSQL. This allows us to perform high-performance similarity searches using Cosine Distance directly in SQL.

backend/graph.py - The Agentic LogicPython
import os
from typing import TypedDict, Optional, List, Dict, Any
from langchain_core.messages import AnyMessage, SystemMessage, HumanMessage, AIMessage
from langchain_openai import ChatOpenAI
from langgraph.graph import StateGraph, END

# Initialize OpenAI model
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)

class AgentState(TypedDict):
    messages: List[AnyMessage]
    current_date: str
    image_base64: Optional[str]
    intent: Optional[str]
    final_response: Optional[Dict[str, Any]]
    plants_context: List[Dict[str, Any]]
    db: Any

def router_node(state: AgentState):
    structured_llm = llm.with_structured_output(schemas.IntentClassification)
    sys_msg = SystemMessage(content="Classify user intent...")
    response = structured_llm.invoke([sys_msg] + state["messages"])
    return {"intent": response.intent}

def logger_node(state: AgentState):
    structured_llm = llm.with_structured_output(schemas.CareLogExtraction)
    sys_msg = SystemMessage(content="Extract plant care actions...")
    extraction = structured_llm.invoke([sys_msg] + state["messages"])
    return {"final_response": {"extraction": extraction.model_dump()}}

# Build the Graph
builder = StateGraph(AgentState)
builder.add_node("router", router_node)
builder.add_node("logger", logger_node)
builder.set_entry_point("router")
builder.add_conditional_edges("router", route_intent, {"logger": "logger", ...})
tarudrishti_app = builder.compile()
backend/models.py - Database SchemaPython (SQLAlchemy)
from sqlalchemy import Column, Integer, String, DateTime, ForeignKey
from pgvector.sqlalchemy import Vector

class User(Base):
    __tablename__ = "users"
    id = Column(Integer, primary_key=True)
    email = Column(String, unique=True, nullable=False)

class Plant(Base):
    __tablename__ = "plants"
    id = Column(Integer, primary_key=True)
    name = Column(String, nullable=False)
    species = Column(String, nullable=False)
    user_id = Column(Integer, ForeignKey("users.id"))
    care_logs = relationship("CareLog", back_populates="plant")

class CareLog(Base):
    __tablename__ = "care_logs"
    id = Column(Integer, primary_key=True)
    action_type = Column(String, nullable=False)
    action_date = Column(DateTime, default=func.now())

class SemanticCache(Base):
    __tablename__ = "semantic_cache"
    query_text = Column(String, nullable=False)
    response_text = Column(String, nullable=False)
    embedding = Column(Vector(1536), nullable=False)
